# LifeWise Family Management Skill

This skill allows AI agents to interact with the LifeWise Family Operating System to check reminders, view subscription plans, and coordinate family schedules.

## Capabilities
- Query family member profiles and permissions
- View upcoming medicine reminders and adherence logs
- Retrieve family bill due dates and payment reminders
- Check Family Ledger expenses and budget statuses
- Fetch active subscription plan details and upgrade options

## API Base
All agent endpoints are rooted at `https://www.lifewiseee.com/api`.
